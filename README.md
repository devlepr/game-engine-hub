# محرك الألعاب — لوحة المشاريع

## الخطوات

1. اعمل مستودع (repository) جديد وعام (public) على GitHub، من غير أي ملفات (empty repo).
2. في Spck Editor: **Import Project → From Zip**، واختار الملف ده.
3. اربط المشروع بالمستودع اللي عملته (Git → Remote → أضف رابط المستودع).
4. اعمل Commit All ثم Push.
5. روح لصفحة المستودع على GitHub → تبويب **Actions** → هتلاقي عملية البناء شغالة تلقائيًا.
6. لما تخلص (خد كام دقيقة)، هتلاقي ملف باسم **app-debug** تحت "Artifacts" — حمّله (هيجيلك كملف zip فيه الـ APK جواه).
7. فك الضغط، وثبّت ملف الـ APK على هاتفك (لازم تسمح بالتثبيت من مصادر غير معروفة أول مرة).

## ملاحظة
كل مرة تعمل فيها push لتعديل جديد، هيتبني APK جديد تلقائيًا في Actions.
